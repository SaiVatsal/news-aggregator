# Project 25: News Aggregator (The Global Dispatch)

A real-time editorial news wire and intelligence aggregator built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Bold Red & White Editorial Palette**: High-contrast front page layout (`#ffffff`, `#dc2626`, `#0f172a`) with Playfair Display and Inter serif/sans typography.
- **Dense Headline & Front-Page Lead Grid**: Structured investigative lead story with supporting multi-column dispatch feeds.
- **Multi-Source Diversity Index**: Source attribution across Nature, FT, MIT Tech Review, and Reuters with fact-verification ratings.
- **Saved Dossier Reading List**: Bookmark articles for offline deep analysis with read-time calculations.
- **Automated Morning Briefing**: Daily 07:00 AM executive digest email subscription service.
- **Categorical Wire Filters**: Instant navigation across Science, Technology, Geopolitics, and Global Economics.

## Getting Started
```bash
npm install
npm run dev
```
